# Changelog

## 1.1.0
- Installer (`MultiOutAudio-Setup-*.exe`) plus portable exe, built automatically by GitHub Actions
- App picker shows each app's real icon and name
- Per-device volume, live level meters, remembered device settings
- Auto-sync: measures each device's real delay with your microphone and equalises them
- Seven themes with anti-aliased original mascots (Sakura, Midnight Idol, Matcha Neko, Cyber Bot, Arctic Penguin, Ghost Mode, Custom)
- Errors are shown in the window instead of failing silently

## 1.0.0
- First release: play one app on several output devices with per-device delay
